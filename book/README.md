## 표기 규칙

| 마크다운 | 원서 요소 |
|----------|-----------|
| `# 01 …` | 장 제목 |
| `## 01-1 …` | 절 제목 |
| `### …` | 절 안의 소제목 |
| `### 하면 된다! — …` | 실습 코너 |
| `#### 01 …` | 실습 단계 제목 (번호 있는 단계) |
| `**01** 본문…` | 제목 없는 실습 단계 |
| `❶ ❷ ❸` | 본문·화면 안 순서 표시 |
| `**볼드**` | 원서의 강조(고딕) 표기 |
| `` `Enter` `` | 키 입력 |
| `**이렇게 써보세요!**` + ``` 코드블록 | 프롬프트 템플릿 |
| `> …` | 제미나이와 주고받은 대화 예시 (프롬프트·답변) |
| `> **여기서 잠깐!** …` | 여기서 잠깐 박스 |
| `### 1분 완성 퀴즈` / `**정답** …` | 절 끝 퀴즈와 정답 |
| `> [참고] …` | 본문 옆 참고 노트 |
| `> [말풍선] …` | 손글씨 말풍선 팁 |
| `*[그림] …*` | 그림·화면 캡처 캡션 |
| `*[그림 속 텍스트] …*` | 도해·캡처 안에 있는 라벨 |
| `<!-- p.21 -->` | 원서 인쇄 쪽 번호 (출처 확인용) |

## 알아 둘 점

- **그림·화면 캡처는 텍스트가 아니다.** 캡션과 그림 속 라벨만 남으므로, 화면 조작을 묻는 문항은 캡처를 봐야 정확하다.
- 제미나이 답변 예시는 원문 그대로 들어 있다. 실제 서비스 응답이 아니라 **원서에 실린 예시**다.
- 요금·모델명·버전은 원서 기준(2026년 7월)이며 본문에도 유동적이라고 명시되어 있다.
- 표는 자동 복원한 것이라 병합 셀이 있는 행은 칸이 밀릴 수 있다. 표 기반 문항은 원본 쪽(`<!-- p.33 -->` 등)을 확인한다.

## 다시 만들기

```bash
python -m pip install pymupdf
python tools/build_book_md.py          # book/ 에 덮어씀
```

장이 추가되면 `tools/build_book_md.py`의 `SOURCES`에 PDF와 장 범위를 더한다. 변환 규칙은 `tools/book2md.py` 상단 주석 참고.
